## Ubuntu 上的 iperf3 網路效能測試教學

iperf3 是一個強大且廣泛使用的網路效能測試工具，主要用於測量兩個節點之間的網路頻寬、抖動和封包遺失率。本教學將介紹如何在 Ubuntu 系統上安裝和使用 iperf3。

## 1. 安裝 iperf3

在兩台需要進行測試的 Ubuntu 系統上，都執行以下命令來安裝 iperf3：

```bash
sudo apt update
sudo apt install iperf3
```

## 2. 核心概念：客戶端-伺服器模式

iperf3 採用客戶端-伺服器模式運作：

-   **伺服器端 (Server)**: 被動接收或發送資料，在您想測量其網路能力的機器上運行。
-   **客戶端 (Client)**: 主動發起連線並發送或接收資料。

## 3. 常見使用場景

- **驗證網路線路品質**: 測試 ISP (網際網路服務供應商) 提供的頻寬是否符合宣稱的規格。
- **內部網路效能評估**: 測量公司或家庭內部網路（如有線、��線 Wi-Fi）的實際傳輸速度。
- **防火牆與 VPN 效能測試**: 評估防火牆或 VPN 通道對網路效能的影響。
- **雲端主機網路測試**: 測量兩台雲端虛擬機之間的網路吞吐量。

## 4. 使用方法

### 步驟一：啟動伺服器端

在作為伺服器的機器上運行以下命令，使其開始監聽來自客戶端的連線：

```bash
# -s 表示啟動伺服器模式
iperf3 -s
```
> **提示**: 您可以使用 `iperf3 -s -D` 讓伺服器在背景以守護進程方式運行。

### 步驟二：從客戶端發起測試

在作為客戶端的機器上運行命令，並將 `<伺服器IP地址>` 替換為伺服器端的實際 IP 地址。

#### TCP 測試 (預設)

- **上傳測試 (Client -> Server)**
  ```bash
  # -c 指定伺服器 IP
  iperf3 -c <伺服器IP地址>
  ```

- **下載測試 (Server -> Client)**
  ```bash
  # -R 表示反向模式
  iperf3 -c <伺服器IP地址> -R
  ```

- **雙向測試 (同時上傳和下載)**
  ```bash
  # -d 表示雙向測試
  iperf3 -c <伺服器IP地址> -d
  ```

#### UDP 測試

- **上傳測試 (限制頻寬為 100Mbps)**
  ```bash
  # -u 表示使用 UDP 協議
  # -b 指定目標頻寬
  iperf3 -c <伺服器IP地址> -u -b 100M
  ```

#### 常用參數

-   `-p <port>`: 指定監聽的端口 (預設為 5201)。
-   `-t <秒數>`: 指定測試時間 (預設為 10 秒)。
-   `-P <數量>`: 指定並行連接數，用於多執行緒測試。

## 5. 解讀測試結果

> **INFO** 測試結果包含以下重要資訊：
> -   **Interval**: 測試的時間區間。
> -   **Transfer**: 在該時間區間內傳輸的總數據量。
> -   **Bitrate**: 計算出的平均頻寬 (這通常是我們最關心的值)。
> -   **Retr**: (TCP) 重傳次數，此數值過高可能表示網路狀況不佳。
> -   **Jitter**: (UDP) 抖動，表示封包到達時間的變動。
>   - **Lost/Total Datagrams**: (UDP) 丟失的 UDP 封包數量和總封包數量。

## 總結
iperf3 是一個簡單、可靠且功能強大的工具，是網路管理員和系統工程師進行網路效能評估和故障排除時的必備利器。透過 TCP 和 UDP 測試，可以全面地了解網路的頻寬、延遲、抖動和封包遺失情況。
