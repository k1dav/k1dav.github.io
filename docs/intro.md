# 這裡是？

S.Feng 的技術手扎，集合各種類別的教學文件，挖坑與填坑的地方。

## 內容分類

- **[Playbooks](/docs/playbooks)**：DevOps 與基礎設施的實作手冊，例如 Authentik SSO、K3s、Headscale、RouterOS、PVE。
- **[技術名詞筆記](/docs/notes)**：AI、MLOps、LLM 與軟體工程常見名詞的整理。
- **[教學系列](/docs/tutorials)**：Docusaurus、GitLab、OpenTalk、Unity AR 的系列教學。
- **[Blog](/blog)**：比較零散的心得與小工具。

## 如何開始？

從側邊欄挑選有興趣的主題，或用右上角的搜尋直接找關鍵字就可以囉！
